## Kesepakatan terbaru

- Yonas adalah manager full-time sejak awal, cinta climbing setelah mencoba tren bersama teman.
- Langsung berlangganan adalah intro tanpa pilihan.
- Satu tahun, 12 bulan × 4 minggu = 48 pilihan utama.
- Label dan deskripsi Kerja / Latihan / Istirahat tetap sama. Keadaan rutin singkat; dialog khas untuk event.
- Memilih Kerja langsung menambah uang, tanpa perlu tawaran tambahan.
- 12 event utama bulanan; kompetisi venue bulan 3, bukan bulan 1 atau minggu 3.
- Mini event di luar pilihan rutin, dapat berupa keputusan tambahan atau kejadian langsung dalam minggu yang sama.
- Mulai sekitar minimal satu kesempatan mini event per bulan; dapat tidak muncul jika syarat tidak terpenuhi.
- Konten bukan pilihan keempat: peluang influencer tumbuh melalui latihan dan mini event.
- Cedera konsekuensi, bukan event wajib. Bulan 6 diisi pelatih tamu.
- Indikator tersembunyi: Uang 50, Stamina 70, Kemampuan 0, Reputasi 0 sebagai nilai awal.
- Uang, Stamina, Reputasi 0–100; Kemampuan tanpa batas maksimal. Uang tidak perlu rupiah.
- Nilai dasar kegiatan: Kerja uang +15/stamina −15; Latihan uang −10/stamina −20/kemampuan +3; Istirahat stamina +35. Masih titik awal untuk diuji keseimbangannya.
- Khusus bulan 1: Latihan kedua membuka mini event; Latihan ketiga menyelesaikan jalur utama.
- Izin mini event mencakup merekam DAN posting sosmed dengan tag. Tidak perlu izin posting terpisah untuk video yang sama.
- Ending influencer, brand ambassador, affiliator, podium 1/2/3, tanpa podium, gagal, serta rahasia menteri tetap dibahas.
